# Internacionalização (i18n) - BestPlayer 8K Mobile

## Visão Geral

O aplicativo mobile agora suporta internacionalização (i18n) com 3 idiomas:
- **Português (pt)** - Idioma padrão
- **Inglês (en)**
- **Espanhol (es)**

## Estrutura de Arquivos

```
src/
├── locales/
│   ├── pt.json    # Traduções em Português
│   ├── en.json    # Traduções em Inglês
│   └── es.json    # Traduções em Espanhol
└── contexts/
    └── LanguageContext.tsx  # Contexto de idioma
```

## Como Usar

### 1. Importar o Hook

```typescript
import { useLanguage } from '@/contexts';
```

### 2. Usar no Componente

```typescript
export default function MyComponent() {
  const { t, language, setLanguage } = useLanguage();

  return (
    <View>
      <Text>{t('auth.login_title')}</Text>
      <Text>{t('common.loading')}</Text>
    </View>
  );
}
```

### 3. Traduções com Parâmetros

```typescript
// No arquivo de tradução (pt.json):
{
  "playlists": {
    "channels_count": "{count} Canais"
  }
}

// No componente:
<Text>{t('playlists.channels_count', { count: 42 })}</Text>
// Resultado: "42 Canais"
```

### 4. Trocar Idioma

```typescript
const { setLanguage } = useLanguage();

// Trocar para inglês
await setLanguage('en');

// Trocar para espanhol
await setLanguage('es');

// Trocar para português
await setLanguage('pt');
```

### 5. Obter Idioma Atual

```typescript
const { language } = useLanguage();

console.log(language); // 'pt', 'en' ou 'es'
```

As traduções são organizadas em categorias:

```json
{
  "common": {
    "success": "Sucesso",
    "error": "Ocorreu um erro",
    "loading": "Carregando..."
  },
  "auth": {
    "login_title": "Acesse sua experiência de streaming",
    "login_button": "Iniciar Sessão"
  },
  "playlists": {
    "title": "Gerenciar Playlists",
    "import_success": "Playlist importada com sucesso!"
  }
}
```

## Funcionalidades

### Detecção Automática de Idioma

O app detecta automaticamente o idioma do dispositivo na primeira execução:
- Se o idioma do dispositivo for pt, en ou es, usa esse idioma
- Caso contrário, usa português como padrão

### Persistência

O idioma selecionado é salvo automaticamente no AsyncStorage e restaurado quando o app é reaberto.

### Fallback

Se uma tradução não for encontrada no idioma atual, o sistema faz fallback para português automaticamente.

## Exemplo Completo

```typescript
import { View, Text, Button } from 'react-native';
import { useLanguage } from '@/contexts';

export default function SettingsScreen() {
  const { t, language, setLanguage } = useLanguage();

  return (
    <View>
      <Text>{t('settings.title')}</Text>
      <Text>{t('settings.language')}: {language}</Text>
      
      <Button 
        title="Português" 
        onPress={() => setLanguage('pt')}
      />
      <Button 
        title="English" 
        onPress={() => setLanguage('en')}
      />
      <Button 
        title="Español" 
        onPress={() => setLanguage('es')}
      />
    </View>
  );
}
```

## Adicionar Novas Traduções

1. Abra os arquivos em `src/locales/`
2. Adicione a nova chave em todos os 3 arquivos (pt.json, en.json, es.json)
3. Use a chave no componente com `t('categoria.chave')`

Exemplo:

```json
// pt.json
{
  "profile": {
    "edit_button": "Editar Perfil"
  }
}

// en.json
{
  "profile": {
    "edit_button": "Edit Profile"
  }
}

// es.json
{
  "profile": {
    "edit_button": "Editar Perfil"
  }
}
```

## Notas Importantes

- O LanguageProvider já está configurado no `app/_layout.tsx`
- Não é necessário adicionar o provider manualmente
- O hook `useLanguage` só funciona dentro de componentes que estão dentro do LanguageProvider
- As traduções são carregadas de forma síncrona, não há necessidade de loading states
